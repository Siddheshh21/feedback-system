# Feedback System Application

A professional, production-ready Angular application for managing user feedback with smooth animations and robust state management.

## Features
- **User Authentication:** Mock session management and role-based indicators.
- **Feedback Management:** Full CRUD (Create, Read, Update, Delete) cycle.
- **Real-time Validation:** Reactive forms with detailed error feedback.
- **Advanced Filtering:** Search, status filtering, and multi-criteria sorting.
- **Polished UI:** Responsive design, glassmorphism, and Angular stagger animations.
- **Mock Backend:** LocalStorage-based API simulation with network delay.

## Setup Instructions

1. **Clone or Copy Files:** Ensure all files are in the project directory.
2. **Install Dependencies:**
   ```bash
   npm install
   ```
3. **Run the Application:**
   ```bash
   npm start
   ```
   Open `http://localhost:4200` in your browser.

4. **Run Unit Tests:**
   ```bash
   npm test
   ```

## Credentials
- Use any name to login (e.g., `Siddhesh`).
- Inclusion of "admin" in the name (e.g., `AdminSiddhesh`) grants admin role indicators.

## Technical Stack
- Angular (Standalone Components)
- Reactive Forms
- RxJS for State Management
- Angular Animations
- Ngx-Toastr for notifications
- Modern CSS (Custom properties, Flexbox/Grid)
